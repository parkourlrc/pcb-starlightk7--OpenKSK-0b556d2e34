# FAQ

**Q:** Will you be doing boards for other models?

**A:** I intend to produce all models of the KSK series that I can obtain. -12, -13, and -21 are queued for reproduction. I am in need of -11 (very rare). If you have one you'd like to donate, please contact me.

**Q:** Can you add support for new lasers?

**A:** It's difficult to say. Not much is known about the program code for these chips, and it's not possible to change the configuration code on the CXP5084 as its burned into the mask rom.

**Q:** I've heard these are used in the Neo Geo CD Frontloader...

**A:** Yes, the Neo Geo CD Frontloader used version -21. This seems to be electrically identical to -14, but with different CXP firmware and a different CXD2500BQ instead of AQ. You may be able to build one off of -14 if you use all of the original chips from a -21, but this has not be confirmed. Feel free to report your results if you try, I don't have a working Neo Geo CD Frontloader at this time to test with. If you have one you'd like to donate, please contact me.

**Q:** What is the difference between CXD2500AQ and CXD2500BQ?

The CXD2500AQ has a lot more memory and can thus handle more advanced jitter and tracking correction.

**Q:** Can I commission you for a pre-built?

**A:** In general I will not have time to do this on an ongoing basis, however, I may irregularly list pre-builts on the Ko-Fi store of units that were used for build validation. Once these are gone, they're generally gone unless there is development need to build another.
