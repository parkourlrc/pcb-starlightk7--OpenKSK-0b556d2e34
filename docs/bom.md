# Bill of Materials (BOM)

## Parts BOM

The [following spreadsheet](https://docs.google.com/spreadsheets/d/1CPgk-KSQ2lsoBCz12uFICEOvwxG4eMLinFVB8mCiDv8) contains a description of required donor parts for the project as well as a mouser-based BOM if you'd like to use as many new parts as possible.

At this time, the new parts BOM is considered beta. I have built a unit that appears to work, but I have not done repeatable builds yet. You may encounter tolerance related issues that require additional troubleshooting. Feel free to report any encountered issues and/or seek help on the project Discord.

Transfer builds should be fully working, but of course the OpenKSK cannot solve mechanical issues. Please perform proper maintenance and alignment on all mechanical parts.
